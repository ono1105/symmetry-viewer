symmetry-viewer  結晶・分子の対称性を学ぶ教材（Windows版）
==========================================================

Python などをインストールする必要はありません。
このフォルダの中に、動かすのに必要なものがすべて入っています。


■ 起動のしかた

※ ダウンロードした zip ファイルの中を直接開いて起動すると動きません。
   必ず zip を右クリックして「すべて展開」を選び、展開してできたフォルダの
   中で起動してください。

1. symmetry-viewer.exe をダブルクリックします。

2. 初めて開くとき、「Windows によって PC が保護されました」という青い画面が
   出ることがあります。発行元の電子署名が付いていないアプリに出る警告です。
   「詳細情報」を押し、表示された「実行」ボタンを押してください。

3. 「アプリケーションがポリシーによってこのファイルをブロックしました」と
   出て起動しない場合は、Windows 11 の「スマート アプリ コントロール」が
   有効になっています。電子署名のないプログラムの一部を拒否する機能で、
   買ったばかりの PC や Windows を入れ直した PC で有効なことがあります。
   「設定」→「プライバシーとセキュリティ」→「Windows セキュリティ」→
   「アプリとブラウザー制御」→「スマート アプリ コントロール」を
   「オフ」にすると起動できます。
   ※ 2026年4月の更新（KB5083769）を適用した Windows 11 では、使い終わったら
     同じ画面で「オン」に戻せます。それより前の Windows 11 では、一度オフに
     すると Windows を入れ直すまで戻せません。オフにしたくない場合は、
     Linux 版か、開発者向けの手順（README）での利用をご検討ください。

4. 黒いウィンドウが開き、少し待つとブラウザで「解析モード」と
   「クイズモード」を選ぶ画面が表示されます。初めて起動するときは、
   ウイルス対策ソフトの検査のために時間がかかることがあります。

ブラウザが開かないときは、黒いウィンドウに表示された
「http://127.0.0.1:（数字）/」のアドレスをブラウザで開いてください。


■ 終了のしかた

黒いウィンドウを閉じてください。
ブラウザのタブを閉じただけでは終了しません。


■ 削除のしかた

このフォルダをまるごと削除してください。ほかの場所には何もインストール
していません。自分で読み込んだ CIF/XYZ ファイルの解析結果は一時フォルダに
置かれ、Windows のディスククリーンアップなどで消えます。


■ 動作環境

- 64ビット版の Windows 10 / 11
- WebGL が使えるブラウザ（Edge、Chrome、Firefox など）
