symmetry-viewer  結晶・分子の対称性を学ぶ教材（Linux版）
========================================================

Python や Node.js をインストールする必要はありません。
このフォルダの中に、動かすのに必要なものがすべて入っています。


■ 起動のしかた

1. このフォルダ（symmetry-viewer）の中で端末を開きます。
   （ファイルマネージャーでフォルダを右クリックし、「端末で開く」を選ぶ）
2. 次のように入力して Enter キーを押します。

       ./symmetry-viewer

3. 少し待つとブラウザが開き、「解析モード」と「クイズモード」を選ぶ
   画面が表示されます。

ブラウザが開かないときは、端末に表示された
「http://127.0.0.1:（数字）/」のアドレスをブラウザで開いてください。


■ 終了のしかた

端末で Ctrl キーを押しながら C キーを押すか、端末を閉じてください。
ブラウザのタブを閉じただけでは終了しません。


■ 削除のしかた

このフォルダをまるごと削除してください。ほかの場所には何もインストール
していません。自分で読み込んだ CIF/XYZ ファイルの解析結果は一時フォルダ
（/tmp）に置かれ、コンピューターの再起動などで自動的に消えます。


■ 動作環境

- x86_64（64ビット）の Linux。glibc 2.27 以降
  （目安: Ubuntu 18.04、Debian 10、Fedora 28 以降）
- WebGL が使えるブラウザ（Firefox、Chrome など）
